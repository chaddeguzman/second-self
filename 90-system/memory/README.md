# System Memory

This folder stores local, private instructions and workflow preferences used by
the Second Self system itself. It is separate from `01-strategy-storage/00
Memory`, which stores Chad's personal identity, experiences, preferences, and
other durable context.

System-memory entries are not wiki-processing inputs and should not be placed in
`01-strategy-storage/01 Notes/00 Raw`.

Private entries in this folder are ignored by Git.
